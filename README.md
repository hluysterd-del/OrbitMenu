# Orbit Menu — Animal Company

In-game menu for Animal Company built on Frida + IL2CPP.

## Usage

Download \Launcher\ folder, run \un.bat\. Animal Company must be running.

## Files

- \rida-il2cpp-bridge.js\ — IL2CPP bridge (stock)
- \Frida-Map.js\ — resolver for AC's obfuscated IL2CPP exports
- \OrbitMenu.js\ — the menu itself
